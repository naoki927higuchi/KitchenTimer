# キッチンタイマー 1.0.0

https://naoki927higuchi.github.io/KitchenTimer/

0からのカウントアップ、3・4・5分や任意時間のカウントダウン、一時停止・再開・リセット、終了音に対応したブラウザ用タイマーです。

index.htmlをブラウザで開くと、オフラインでも使えます。計測中はページを開いたままにし、端末のスリープを避けてください。再読み込みで計測はリセットされます。
